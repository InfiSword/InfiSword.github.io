# Feature Specification: 다이어그램 글자 가독성 수정

**Created**: 2026-10-19
**Status**: Reviewed
**Input**: 프로젝트 관계도·설명도·파이프라인의 회색/검은색 일반 글자는 흰색으로 변경하고, 이전 글에서 의미를 구분하던 강조색은 유지한다.

## User Scenarios & Testing
### User Story 1 (P1)
방문자가 각 프로젝트의 도표 제목, 설명, 분기 및 SVG 라벨을 선명하게 읽는다.
**Acceptance**: 6개 프로젝트 도표에서 일반 글자는 흰색, 역할·단계·분기 강조는 기존 색 계열로 표시되며 HTML 텍스트는 배경과 최소 4.5:1 대비를 제공한다.
### Edge Cases
- 밝은 시스템 테마에서도 흰 글자가 밝은 패널에 묻히지 않는다.
- 어두운 시스템 테마와 모바일에서 동일하게 읽을 수 있다.
- SVG 도형·선과 코드 구문 강조는 보존한다.

## Requirements
- FR-001: 도표의 HTML/SVG 일반 텍스트를 흰색으로 표시하고 기존 의미별 강조색은 대비가 높은 색조로 유지한다.
- FR-002: 도표 및 내부 박스 배경을 흰 글자와 대비되는 어두운 색으로 표시한다.
- FR-003: 글자 크기, 내용, 레이아웃, 동작을 보존한다.
- FR-004: 일반 본문 및 도표 밖 카드에는 변경을 확산하지 않는다.

## Success Criteria
- 모든 프로젝트에서 도표 텍스트 색상과 대비 검증 성공.
- 데스크톱/모바일 및 밝은/어두운 시스템 테마에서 검증 성공.
- 사이트 빌드 및 기존 회귀 테스트 통과.

## Assumptions
기존 pf-visual-frame 도표·설명 패널과 캡션을 대상으로 하며, 이미지 픽셀과 코드 구문 색은 보존한다.
