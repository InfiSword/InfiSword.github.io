ARCHITECTURE REPORT // FILE_TOWER_DEFENSE

File Tower Defense: 시스템 리팩토링 및 최적화

📐 1. 아키텍처 전면 재설계 (UI → World)

RectTransform(UI) 기반의 유닛 시스템을 GameObject(Transform) 기반으로 전환하여 좌표계 종속성을 제거하고 렌더링/연산 비용을 획기적으로 절감했습니다.

⚡ 2. 공간 분할 최적화 (O(1) Search)

전체 그리드 순회 대신 3x3 국소 영역 탐색을 도입하여 검색 시간 복잡도를 O(n)에서 O(1)로 단축, 10배 이상의 탐색 성능 향상을 달성했습니다.

🔒 3. 트랜잭션 기반 배치 시스템

원자적(Atomic) 검증 로직을 설계하여 유닛 이동 및 폴더 패킹(Zip/Unzip) 시 데이터 불일치를 방지하고 실패 시 이전 상태로 안전하게 롤백합니다.

🎯 4. 1€ 필터 및 중앙 집중식 입력 제어

InputManager 중앙화로 불필요한 레이캐스트를 제거하고, One Euro Filter를 탑재해 화면 왜곡 노이즈 환경에서도 떨림 없는 마우스 조작감을 실현했습니다.

ARCHITECTURE REPORT // WINAPI_DONT_STARVE

Don't Starve 모작: 공간 분할 및 렌더링 최적화

🗺️ 1. 그리드 공간 분할 (Grid Partitioning)

월드 전체를 일정한 그리드 셀 단위로 분할하여 관리함으로써 오브젝트 간의 충돌 및 갱신 연산을 인접 셀 단위로 제한했습니다.

👁️ 2. 뷰포트 컬링 (Viewport Frustum Culling)

카메라 가시 영역 내에 포함된 타일과 오브젝트만 선별하여 DrawCall을 호출, 화면 밖 80% 이상의 불필요한 비트맵 연산을 완전 배제했습니다.

🖼️ 3. 더블 버퍼링 & 리소스 캐시 매니저

메모리 DC를 활용한 더블 버퍼링으로 GDI 깜빡임을 제거하고, 스프라이트 비트맵을 키 기반으로 캐싱하여 메모리 누수를 원천 차단했습니다.

🧩 4. 컴포넌트 기반 객체 아키텍처

상속의 깊이를 줄이고 Transform, Collider, Renderer 등의 기능을 독립 컴포넌트로 분리하여 유연한 엔티티 확장을 달성했습니다.
